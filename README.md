Echoes Between Dimensions

A hybrid Third-Person / First-Person shooter developed in Unity 6 for ECE4208 — Computer Design and Performance Evaluation (Game Programming).

The player is stranded in a mysterious ocean port controlled by hostile robotic entities. 
To escape, you must locate a remote scanner, activate all 3 signal towers, and reach the portal 
before the robots take you down.

Built with:
- Unity 6 (6000.0.58f2)
- C# / New Input System
- Cinemachine for camera transitions
- NavMesh for enemy AI pathfinding
- Unity Animator with Root Motion

Key features:
- Hybrid TP/FP camera system (hold RMB to switch)
- Enemy FSM: Sleep → Wake → Chase → Attack → Patrol
- Scanner system with line-of-sight and 3-second activation
- Gun combat with heat system and overheat mechanic
- Portal cutscene on all towers activated
- Water respawn with no progress loss
